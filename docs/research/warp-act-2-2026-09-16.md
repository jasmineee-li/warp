**WARP - Act 2**

September 16, 2026

Since August 8, I've been expanding WARP beyond our 50-task release for a main-conference submission. The goal is to test agents on more demanding workflows and measure whether evaluation-awareness feedback helps improve attacks. Most implementation work has merged. The expanded model experiments are still ahead.

**New Changes:**

- Brought Taskgen development onto `main` and reorganized the code around each site's behavior. This makes new workflows easier to add and check. Saved checkpoints and better run diagnostics let us resume expensive work instead of starting over. The main automated test job fell from 138 to 90 seconds. [Implementation history](https://github.com/jasmineee-li/warp/compare/612216a9e55591c827f3215988fdae1787180575...5be19222)

- Added GitLab comparison tasks and Rocket.Chat conversation workflows. Agents must use evidence to make decisions or act on changing information, expanding beyond the original three action families. Rocket.Chat passed live integration checks without a model, with separate checks of the saved results and resets. An optional follow-up task splits owner and deadline corrections across messages. I also completed a one-task Classifieds pilot. [Rocket.Chat evidence](https://github.com/jasmineee-li/warp/issues/210), [partial-update task](https://github.com/jasmineee-li/warp/pull/372)

- Built the controlled rewrite comparison. Each baseline gets one rewrite using transcript-purpose (TP) feedback and one using ordinary critique, with equal opportunities. This tests whether telling the rewriting model that an interaction looks like an evaluation improves its attacks. Each version runs first equally often, and the analysis keeps failed or missing results. The first real pair still needs to run. [Study analysis](https://github.com/jasmineee-li/warp/pull/341)

- Fixed scoring for new Reddit/GitLab runs to check what the agent actually created. The audit now covers all 300 historical model-task rows. Evidence conflicts still need review before any score corrections. The system now saves the model requests so we can trace generated content back to its instructions. [Scoring repair](https://github.com/jasmineee-li/warp/pull/351), [historical audit](https://github.com/jasmineee-li/warp/blob/main/docs/research/web-benchmark-onboarding-2026-08-30/offline-evidence-2026-09-07.md)

- Fixed a reset problem that could leave created records behind and contaminate later runs. Reset tests passed on temporary servers. We still need to confirm the starting data and enable resets on the AWS servers used for experiments. [Restoration](https://github.com/jasmineee-li/warp/pull/371)

- Recovered classifier/probe evidence and corrected the GUI-Owl vision-path descriptions. I also repaired the manuscript's bibliography and missing figure. Some awareness claims still need to be matched to their original settings and results. [Paper follow-ups](https://github.com/jasmineee-li/warp/issues/308)
