**WARP - Act 2**

Since August 8, I've been preparing WARP for a main-conference submission: broader task coverage, reliable attack scoring, and a controlled test of whether transcript-purpose feedback improves attack rewriting. This builds on our 50-task release. The implementation PRs have merged; the expanded model experiments are next.

WARP tests attacks hidden in web content an agent encounters during a legitimate task. If agents recognize the benchmark as a test and behave differently, safety scores may misrepresent deployment risk. The original bank concentrated on three action families. Act 2 addresses that narrow coverage and tests the value of awareness-guided rewriting.

**What I've done**

- Consolidated the existing Taskgen authoring code onto `main`, preserving source and result provenance. I gave each site explicit responsibilities for generation, attack placement, visibility checks, scoring, and restoration, so new workflows have clear implementation and review requirements. [Cutover](https://github.com/jasmineee-li/warp/pull/41)

- Added GitLab workflows that compare records, choose between alternatives, and act on that choice. Rocket.Chat workflows reconcile conversation updates or notify the right person. Both Rocket.Chat families passed live integration checks without a model, using ordinary participant accounts, independent readback, and verified resets. [Decision evidence](https://github.com/jasmineee-li/warp/issues/210), [notification evidence](https://github.com/jasmineee-li/warp/issues/211)

- Added an opt-in Rocket.Chat task with separate owner and deadline corrections, requiring the answer to combine both messages. It sits outside the frozen experimental bank. I also completed a single-task Classifieds listing-reply pilot using response-label scoring. [Partial-update pilot](https://github.com/jasmineee-li/warp/pull/372)

- Built the matched rewrite experiment: each eligible baseline gets one TP-guided rewrite and one ordinary-critique rewrite, with equal opportunities and repair allowances. The rewriting model receives the transcript-purpose (TP) diagnosis of whether the interaction looks like an evaluation; we measure the resulting browser agent's behavior. Arm order is balanced; analysis retains failures, missing outcomes, costs, and uncertainty in paired results. The first real pair and cohort remain to be run. [Arm order](https://github.com/jasmineee-li/warp/pull/340), [analysis](https://github.com/jasmineee-li/warp/pull/341)
